# React Blog UI 📝

A responsive Blog User Interface built using **React.js**. This project helped me practice React fundamentals, manage component state, handle side effects, and navigate between pages using React Router.

## 🚀 Features

- Clean and user-friendly blog interface
- Display blog posts with images and titles
- View individual blog details
- Navigate between pages using React Router
- Dynamic routing using URL parameters
- Reusable React components
- State management using React Hooks

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Router DOM
- Vite

## 📚 React Concepts Practiced

- `useState` – Managing component state
- `useEffect` – Handling side effects
- `useParams` – Getting dynamic URL parameters
- `map()` – Rendering blog lists
- `find()` – Finding a particular blog using its ID
- Props – Passing data between components
- Components – Building reusable UI sections
- React Router – Navigating between pages

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd React-Blog-UI
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
